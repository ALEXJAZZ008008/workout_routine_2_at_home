{\fontsize{10.2}{11.4}\selectfont\bfseries PROGRESSION}\par\vspace{0.14cm}
{\fontsize{7.05}{8.25}\selectfont
3 sets (+1 total): 8/8/8 $\to$ 9/8/8 $\to$ 9/9/8 $\to$ 9/9/9.\quad
2 sets (+1 total): 8/8 $\to$ 9/8 $\to$ 9/9.\\[-1.4pt]
10--20 (+2 total): 10/10 $\to$ 11/11 $\to$ 12/12. Continue the same pattern to the top of each range.\\[-1.4pt]
Effort: $\sim$1 RIR on working sets; final set may reach 0--1 RIR. Last rep hard but technically clean.\\[-1.4pt]
At ceiling: increase to the next load and plan the range minimum. Actual reps may initially fall below the range.\\[-1.4pt]
If the planned target is missed, record actual and repeat the same target until achieved; then resume normal progression.\\[-1.4pt]
A target missed at the programmed pace counts as a miss; do not add rest solely to achieve it.\\[-1.4pt]
Individual stalls are tolerated while other exercises progress; do not reset or alter that exercise automatically.\\[-1.4pt]
Recovery: if $\geq$50\% of exercises miss planned progression or regress for 3 consecutive sessions, skip the next scheduled session.\\[-1.4pt]
Hip abduction: each programmed set includes both sides; both sides must achieve the planned target before progression.
}
\end{tcolorbox}
